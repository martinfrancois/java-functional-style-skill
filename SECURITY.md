# Security Policy

If you believe you've found a security issue in Java Functional Style Skill for AI Agents, do not
open a public issue.

Use GitHub private vulnerability reporting when available:

<https://github.com/martinfrancois/java-functional-style-skill/security/advisories/new>

If private vulnerability reporting is unavailable, email:

<github.security.java-functional-style@fmartin.ch>

Use the subject:

```text
Security report: java-functional-style-skill
```

Share only the minimum information needed to start triage. Do not include secrets, private hosted
eval artifacts, local machine paths, or non-public tokens.

This repository is a Tessl skill and eval suite, not a runtime application. Still report issues such
as accidental secret exposure, unsafe workflow behavior, or published private metadata.
